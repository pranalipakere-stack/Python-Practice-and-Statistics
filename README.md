# Python Practice and Statistics

## About This Repository
This repository contains my Python practice work as part of my journey toward becoming a Data Analyst. It includes practical exercises covering Python fundamentals, data structures, string operations, and statistical concepts.

## Topics Covered

### 1. Python Fundamentals
- Lists and loops
- Even and odd number separation
- Basic Python operations

### 2. Sets
- Creating sets
- Adding and updating elements
- Removing elements using `remove()` and `discard()`
- Set operations:
  - Union
  - Intersection
  - Difference

### 3. Dictionaries
- Creating dictionaries
- Accessing and updating values
- Adding and deleting key-value pairs
- Dictionary methods: `keys()`, `values()`, `items()`, `pop()` and `popitem()`

### 4. String Operations
- String immutability
- Uppercase and lowercase conversion
- String formatting and cleaning
- Replace, split and join
- Searching and counting
- String validation methods

### 5. Statistics and Data Analysis
- Normal distribution
- Histogram and normal distribution curve
- Mean and standard deviation
- Empirical rule (68–95–99.7 rule)
- Skewness and kurtosis
- Outlier detection using box plots
- Q-Q plots for normality checking
- Data standardization using StandardScaler

## Tools and Libraries
- Python
- NumPy
- Pandas
- Matplotlib
- SciPy
- Scikit-learn
- Jupyter Notebook

The purpose of this repository is to strengthen my Python programming and statistical knowledge through hands-on practice and improve my analytical skills for a career in Data Analytics.
